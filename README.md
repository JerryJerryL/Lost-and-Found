# 宇宙失物招领处 / Lost-and-Found

《宇宙失物招领处》是 Project 404 的早期网页试玩 Demo。

玩家扮演第404号宇宙失物招领处的试用期管理员，每天接收、调查并处理来自不同星球、时间线和异常事故中的失物。

表面上，这是一份行政工作：  
查编号、核来源、匹配物主、扫描异常、填写审查清单，并在归还、封存、销毁或出售之间做出处理决定。

但随着档案逐渐展开，玩家会发现这些失物并不是随机漂来的。它们指向一场被公司隐瞒的复制灾难，也指向第404号站点本身的异常。

> 你处理的不只是失物。  
> 你也可能是其中之一。

## 当前版本

这是一个早期可玩原型，主要用于测试核心玩法、文本节奏、系统流程和整体氛围。

当前版本包含：

- 失物处理流程
- 五项调查系统
- 标准审查清单
- 四种处理决定：归还、封存、销毁、出售
- 资源变量：资金、污染、信任、行动点
- 每日审查报告
- 白天工作界面
- 员工休息室
- 商店与道具系统
- 本地浏览器存档

## 核心玩法循环

1. 阅读每日信件
2. 选择今日失物
3. 调查编号、来源、物主、异常和可读取内容
4. 根据调查结果更新审查清单
5. 做出处理决定
6. 提交今日审查
7. 回到员工休息室
8. 休息、购买补给，并进入下一天

## 项目风格

本项目希望结合以下元素：

- 复古科幻
- 太空官僚系统
- 异常失物档案
- 碎片化叙事
- 轻度资源管理
- 机械终端式 UI
- 黑色幽默
- 温柔但怪异的情绪底色

游戏长期主题围绕“归属”“记忆”“替代品”“公司化回收系统”以及“被归还的东西是否仍是原物”展开。

## 技术说明

当前 Demo 使用：

- HTML
- CSS
- JavaScript
- JSON 数据文件
- GitHub Pages

存档目前使用浏览器 `localStorage`。  
这意味着进度只保存在同一设备、同一浏览器中。更换设备、浏览器或清除缓存后，存档可能消失。

## 当前测试重点

这个版本主要用于观察：

- 玩家是否理解每天要做什么
- 调查按钮和审查清单是否清楚
- 处理决定是否有意义
- 资金、污染、信任和行动点是否形成压力
- 白天工作与休息室之间的节奏是否顺畅
- 文本和氛围是否能让玩家想继续玩

## 希望获得的反馈

如果你试玩了这个 Demo，可以重点反馈：

- 你是否知道下一步该做什么？
- 哪个失物最让你印象深刻？
- 哪个系统让你困惑？
- checklist 是否帮助你做决定？
- 处理决定是否有取舍感？
- 数值变化是否足够清楚？
- 休息室是否有必要、有氛围？
- 故事是否让你想继续玩？
